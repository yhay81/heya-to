# 部屋灯

協力ライブの5桁、残り席、固定条件を12分だけ公開する、匿名の短期募集盤です。

- 募集主は5桁と残り席を置き、満室時に消灯できます。
- 参加者は5桁をコピーし、入室できたかを匿名で返せます。
- 名前、連絡先、画像、プレイヤーID、チャット、決済は扱いません。
- 代行、売買、BOT、マクロ、チートの募集を入力時に拒否します。
- 募集主の権限はURLフラグメントに置き、サーバーにはSHA-256ハッシュだけを保存します。
- Cloudflare Workers、Hono JSX、Vite+、D1で動作します。アカウント認証は不要です。

部屋灯は非公式サービスです。ゲーム内の表示と公式ガイドラインを正本として確認してください。

## 開発

```powershell
npm install
npm run check
npm test
npm run build
```

データ境界は `PRIVACY.md`、安全上の連絡先は `SECURITY.md` を参照してください。
